# new-project-agents

A personal portfolio site with projects and posts, published by GitHub Pages at
[chamaya00.github.io/new-project-agents](https://chamaya00.github.io/new-project-agents/).

Content is Markdown in `content/`. The site is generated into `docs/` by
`npm run build` and committed, so what Pages serves is what CI tested. See
[CLAUDE.md](CLAUDE.md) for how to add a post or a project, and
[docs/decisions/](docs/decisions/) for why it is built this way.

This repository is also the sandbox that exercises the
[agent-factory](https://github.com/chamaya00/agent-factory) workflow end to end.
