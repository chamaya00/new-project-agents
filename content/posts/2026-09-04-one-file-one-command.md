---
title: One file, one command
date: 2026-09-04
summary: Why the edit path is a product requirement rather than a convenience.
---

Most personal sites are abandoned at the point where publishing costs more than
writing. The fix is not a better editor, it is making the edit path short enough
that nothing can accumulate friction: one file in, one command, done.

That constraint is also what makes the site agent-editable. A coding agent
connected to the repository can add a post the same way a person does, because
there is no browser step in the middle to automate around.
